# Cronos

## My personal tracker built from scratch in C.

Chronos is a personal project aimed to tracking how I spend my time. It started as a way to practice C on Linux while building something useful for my everyday life.

## Motivation

This project is an opportunity to learn C by building something from the ground up, understanding how each component works and gradually turning a simple command-line tool into a more complete app. :)
